# Store Review Notes

민턴동은 배드민턴 동호회 운영 및 오프라인 레슨 예약 서비스입니다.

핵심 기능:

- 동호회 생성 및 가입
- 회원과 출석 관리
- 경기 기록
- 오프라인 배드민턴 레슨 확인 및 결제
- 배드민턴 대회 정보 확인

레슨 결제는 앱 외부의 실제 체육시설/코치가 제공하는 오프라인 서비스에 대한 결제입니다. 앱 내
디지털 콘텐츠나 기능을 구매하는 결제가 아닙니다. PortOne/KG이니시스를 이용하며 결제 금액과
상태는 민턴동 서버에서 다시 검증합니다.

심사 테스트 경로:

1. 제공된 review 계정으로 로그인
2. 동호회 탭에서 가입 클럽과 운영 화면 확인
3. 레슨의 공개 상품과 checkout 확인
4. 대회 탭에서 목록과 외부 원본 링크 확인
5. 마이 → 계정 설정에서 계정 삭제 위치 확인

계정 삭제 위치는 `마이 → 계정 설정 → 계정 삭제`입니다. Apple 로그인 계정은 삭제 직전에 Apple
연결 해제를 위한 재인증을 한 번 거치며, 연결 해제에 실패하면 민턴동 계정도 삭제하지 않습니다.

결제 승인을 완료하지 않아도 상품, 가격, 취소·환불정책과 핵심 앱 기능을 검토할 수 있습니다.
외부 대회 페이지는 정보 출처이며 민턴동 내부 참가 신청/결제가 아닙니다.
